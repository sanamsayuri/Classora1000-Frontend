# SchoolXP - Frontend Service

This is the frontend component of the SchoolXP SaaS Educational ERP System.

## Stack
- Next.js (App Router)
- React 19
- Tailwind CSS v4
- TypeScript

## Requirements
- Node.js > 18.17 (LTS recommended)
- Next.js requires `.env` or `.env.local` to be present for various variables.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

For comprehensive architectural details and full setup, see the **[Root Repository README](../README.md)**.
